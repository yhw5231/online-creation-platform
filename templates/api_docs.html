API 接口文档
通过 API Key 调用生成图片，积分扣减规则与网页完全相同
1. 获取 API Key

登录后进入 个人主页 →「API Key」卡片点击「生成 API Key」。

  • 新 Key 明文仅显示一次，请立即复制保存；数据库只存 SHA-256 哈希，无法找回明文
  • 随时可「刷新 Key」：旧 Key 立即失效
  • 每个用户同时只有一个有效的 API Key
2. 认证方式

所有接口请求头携带 Key 即可（二选一）：

Authorization: Bearer sk-xxxxxxxx
X-API-Key: sk-xxxxxxxx

Key 缺失 / 无效 / 账号被禁用均返回 HTTP 401。

3. 生成图片

POST /api/v1/generate（JSON 请求体）

参数必填说明
prompt是提示词，最长 4000 字
channel否渠道下标字符串（0 开始，如 "0"），留空自动选第一个普通渠道
n否生成数量，1–4，默认 1
aspect_ratio否1:1 / 16:9 / 4:3 / 3:4 / 9:16 / 21:9，默认 1:1
resolution否分辨率档位（如 1k/2k/4k），须为该渠道支持的档位，默认取渠道第一个档位；渠道不支持时返回 400

返回格式由系统后台自适应固定为 URL，不接受 response_format 参数。

成功响应（任务异步处理，立即返回）：

{"ok":true,"task_id":123,"message":"任务已提交"}
4. 查询任务状态

GET /api/v1/status?task_id=xxx

成功响应：

{
  "ok": true,
  "task_id": 123,
  "status": "success",
  "prompt": "一只猫",
  "images": ["/images/xxx.png"],
  "error": "",
  "created_at": "2026-08-16T12:00:00+08:00"
}
  • status：processing（生成中，建议每 2–3 秒轮询）/ success（成功，images 为图片路径列表）/ failed（失败，error 为原因，积分已退回）
  • 图片拼接站点地址即可下载（无需 Key）：http://127.0.0.1:8900/images/xxx.png
  • task_id 不存在或不属于该 Key 的账户：返回 404
5. curl 完整示例
# 提交生成任务
curl -X POST http://127.0.0.1:8900/api/v1/generate \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"一只猫","n":1,"resolution":"2k"}'

# 查询任务状态（循环轮询直到完成）
for i in $(seq 1 30); do
  RESP=$(curl -s "http://127.0.0.1:8900/api/v1/status?task_id=123" \
    -H "Authorization: Bearer sk-xxxxxxxx")
  echo "$RESP"
  echo "$RESP" | grep -q '"processing"' || break
  sleep 2
done

# 下载图片（无需 Key）
curl -o cat.png "http://127.0.0.1:8900/images/xxx.png"

更多 Python 调用示例见项目 docs/api.md。

6. 错误码
HTTP说明
400参数错误：无效 JSON（如 channel 传了数字）/ prompt 为空或超长 / 渠道无效 / 分辨率不属于该渠道，error 字段为具体原因
401API Key 缺失或无效
402积分不足（error 字段含所需积分，此次不扣分）
404task_id 不存在或不属于该 Key 的账户
405使用了错误的 HTTP 方法
500系统繁忙 / 任务创建失败（此情况积分已退回）
