图片存储

生成的图片默认保存在服务器本地（data/images）。可启用外部长期存储：图片在服务器下载落盘后会自动上传一份到外部存储（S3 兼容对象存储 / WebDAV / 通用 POST 上传接口），此后服务器本地文件即使被自动清理，用户仍可通过“备用下载”地址取回图片。图片的存储方式与远端路径会记录在每条记录中。

S3 为对象存储服务地址；WebDAV 为根目录地址；POST 为完整的上传接口 URL。
S3 签名所用区域（如 us-east-1 / ap-northeast-1 / oss-cn-hangzhou），默认 us-east-1。
上传到外部存储的目录前缀，如 images；留空则直接放在根下。POST 方式下额外作为 path 表单字段提交。
自动清理

防止服务器磁盘被历史图片占满。启用后按以下两条规则自动清理：① 超过保留天数的旧记录会被清理；② 本地图片目录超过磁盘上限时按旧到新删除，直到低于上限。已上传外部存储的图片在清理时仅删除本地文件，保留记录与备用下载地址，用户可以继续访问。

超过该天数的旧记录会被清理（默认 30 天）。
data/images 目录超过该大小即触发按旧到新清理（默认 2048 MB）。
