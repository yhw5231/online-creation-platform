# 在线创作平台

基于 Go 的 AI 图片创作平台，采用积分制运营，支持每日签到、兑换码兑换、生成消耗与管理后台。

## 功能特性

- **AI 图片创作**：调用 Grok 类图片生成 API，选择生成渠道（下拉展示渠道名）/生成数量/宽高比/分辨率/返回格式；任务异步提交、后台生成，页面自动轮询同步状态；支持普通与 NSFW 双渠道（系统设置可配置多接口列表并标记 NSFW 渠道，创作页开启 NSFW 后自动切换到 NSFW 渠道，每个渠道使用自己配置的默认模型）
- **积分体系**：注册赠送、每日签到（固定 / 随机两种模式）、兑换码兑换、创作按张扣费（生成失败自动退回）
- **积分明细**：完整账本记录每一笔获得与消耗
- **账户自服务**：修改密码、头像下拉菜单、个人主页（积分/创作/动态总览）、积分明细自助查询
- **管理后台**：数据概览仪表盘、用户管理（搜索 / 启用 / 禁用 / 授管理员 / 调整积分、分页）、兑换码生成 / 分页 / 作废 / 一键清理 30 天未使用码、系统设置（含一键恢复默认）、一键下载数据库备份
- **创作记录**：预览、查看大图（灯箱内可直接下载原图）、删除（连带清理本地图片），附带生成规格与累计消耗统计；失败任务显示原因并已退回积分
- **排行榜与规则**：公开创作排行榜（排除管理员，仅展示今日创作次数与累计创作次数）、积分规则页实时反映后台配置
- **落地页作品墙**：未登录首页展示最近公开创作，灯箱放大
- **体验细节**：全站分页带页码直跳、"每日签到"导航红点提醒、登录/注册失败保留用户名、回到顶部按钮、时间统一本地时区
- **第三方登录**：支持 Linux.do OAuth

## 快速开始

> 完整部署流程（拉取代码 → 环境准备 → 构建 → 配置 → 启动 → 后台初始化设置 → 反向代理/HTTPS → 运维与排查）参见 **[docs/deployment.md](docs/deployment.md)**。

### 1. 拉取代码

```bash
git clone https://github.com/yhw5231/online-creation-platform.git
cd online-creation-platform
```

### 2. Docker 部署（推荐）

```bash
docker compose up -d --build
```

服务运行在 `8900` 端口，数据保存在 `./data`，静态资源挂载自 `./static`。

> 容器以非 root 用户（UID 1000）运行；./data 与 ./static 为 bind-mount，宿主目录需允许 UID 1000 写入，否则日志会出现 WARN: cannot persist session key ... using in-memory key（会话密钥改用内存密钥，建议显式设置 SESSION_SECRET）。

### 3. 源码运行（本地开发）

```bash
go build -o app.exe .
# 可选：设置会话密钥与端口
# set SESSION_SECRET=至少16位的随机字符串
# set PORT=8900
./app.exe
```

### 4. 初始化

首次启动会自动创建 `data/creation.db` 数据库，并生成默认管理员 `admin / admin123`（**请尽快在后台修改**）。默认监听 `:8900`。

生产部署还需在管理后台配置：图片生成渠道（API 地址 / Key / 模型 / NSFW 渠道）、注册 / 签到 / 积分规则、第三方登录等，详见 [docs/deployment.md](docs/deployment.md) 第 7 节。

运行单元测试（工具函数与安全行为校验）：`go test ./...`。

## 环境变量

| 变量 | 说明 | 默认 |
|------|------|------|
| `PORT` | 监听端口 | `8900` |
| `SESSION_SECRET` | 会话签名密钥（建议 >=16 位随机串）。不设置时首次启动会自动生成随机密钥并存入 `data/.session_secret` 复用 | 自动生成 |
| `COOKIE_SECURE` | 设为 `true` 时仅通过 HTTPS 下发会话 Cookie | 关闭 |
| `TRUST_PROXY_HEADERS` | 反向代理部署时设为 `true`，登录限流改用 `X-Forwarded-For` 真实客户端 IP | 关闭 |

## 安全特性

- **CSRF 防护**：所有写入型表单与破坏性操作均携带一次性会话令牌（签到/生成等重放防护），配合 `SameSite=Lax` Cookie 双重防护
- **登录限流**：同一 IP 连续失败 5 次后锁定 10 分钟，抵御密码爆破
- **并发扣减安全**：生成、签到、兑换均以"条件更新 + 受影响行数"落地，杜绝积分被扣成负数或重复发放
- **签到随机公平**：随机签到积分用 `crypto/rand` 加密级随机源，无法被推算
- **会话安全**：登录 / 第三方登录成功后重置会话 ID，防止会话固定攻击
- **响应安全头**：`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Content-Security-Policy`、`Permissions-Policy` 自动附加
- **服务稳健性**：HTTP 服务配置读写超时（防慢连接耗尽资源），收到退出信号后优雅停机（等待在途请求完成再退出）
- **权限实时校验**：后台操作逐请求对比数据库角色，禁用/降级立即生效
- **匿名化密码**：密码仅存 bcrypt 哈希，修改密码需验证原密码
- **请求体上限**：登录、注册、生成、签到、兑换等所有写请求限制请求体 ≤2MB，超大表单无法撑爆服务器内存
- **上游错误防护**：图片接口错误详情裁剪至 300 字符、下载/响应体积封顶，防止异常上游拖垮页面与内存
- **健康检查**：`/health` 返回 `{"status":"ok"}`，Docker Compose 已内置探活配置

## 系统设置项（管理后台）

- **基本信息**：站点名称、单张消耗积分
- **注册设置**：开放注册、是否需要注册码、初始积分
- **签到设置**：开关、模式（固定 / 随机）、额度范围
- **图片生成接口**：多渠道列表模式（可新增/删除接口行），每个渠道可配置名称、API 地址、API Key、默认模型，并可标记是否为 **NSFW 渠道**（创作页开启 NSFW 后自动走该渠道；普通创作走非 NSFW 渠道）
- **第三方登录**：Linux.do 的 Client ID / Secret / Redirect URI

> API 接入格式参见 `docs/grok-image-api.md`。

```
├── main.go            # 服务入口与全部处理器
├── models/            # 数据库模型、连接、配置
├── services/grok.go   # Grok 图片生成 API 客户端
├── templates/         # HTML 模板（前台 + 管理后台）
├── static/            # CSS / JS / 图标
└── data/              # SQLite 数据库与生成的图片（运行时）
```
